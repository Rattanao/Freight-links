Check EDI Freight Links

เทียบ MANIFEST ของสายเรือกับ ENTER ของลูกค้าให้ครบทุก B/L แล้วออกรายงาน EDI.xlsx แบบใส่สี จุดไหนไม่ตรงเห็นได้ทันทีก่อนยื่นใบขน

MANIFEST.xls+ ENTER.pdf→ EDI.xlsx
ตรวจออนไลน์ (ไม่ต้องติดตั้ง) ดาวน์โหลดโปรแกรม (ZIP) เปิดหน้า GitHub

ติดตั้งครั้งแรก

ทำครั้งเดียวต่อเครื่อง ใช้ Windows

  1. ติดตั้ง Python 3 จาก python.org/downloads

    หน้าแรกของตัวติดตั้ง ติ๊ก ☑ Add python.exe to PATH ก่อนกด Install Now

  2. ดาวน์โหลดโปรแกรม กดปุ่ม “ดาวน์โหลดโปรแกรม (ZIP)” ด้านบน

    คลิกขวาที่ไฟล์ ZIP → Extract All แล้วเก็บโฟลเดอร์ไว้ที่ไหนก็ได้ เช่น Documents

  3. รันครั้งแรกต้องต่ออินเทอร์เน็ต

    โปรแกรมจะติดตั้งไลบรารีที่ต้องใช้ (openpyxl, xlrd, pymupdf) ให้เองอัตโนมัติ

ใช้งานทุกครั้ง

  1. วางไฟล์ในโฟลเดอร์ input

    ลบไฟล์งานเก่าออกก่อน แล้ววางไฟล์ MANIFEST (.xls/.xlsx) และ ENTER (.pdf) อย่างละ 1 ไฟล์ ถ้าชื่อไฟล์ขึ้นต้นด้วย MANIFEST และ ENTER จะดีที่สุด

  2. ดับเบิลคลิก run-check-edi.bat

  3. พิมพ์ SHED NO. ของงาน แล้วกด Enter

    เช่น 0141 ถ้าไม่รู้ให้กด Enter ข้ามได้ โปรแกรมจะใช้กฎ SHED มาตรฐานแทน

  4. เปิดผลที่ output\EDI.xlsx

    หน้าจอดำจะสรุปจุดที่ต้องตรวจให้ด้วย ถ้าเปิด EDI.xlsx ค้างไว้ใน Excel ต้องปิดก่อนรันใหม่

อ่านรายงาน EDI.xlsx

หนึ่งแถวต่อหนึ่ง B/L ช่องซ้ายสุดสรุปว่าแถวนั้นต้องดูอะไร ค่าของ ENTER กับ MANIFEST วางคู่กันทุกหัวข้อ

สรุปผลเร่งด่วนB/L NO.CNTRS NO. (ENTER)CNTRS NO. (MANIFEST)G.W. KGM (ENTER)G.W. KGM (MANIFEST)STATUS
✓ ผ่านHASLK…0001AABCU0686534ABCU06865342,721.0002,721.000LCL/CFS
⚠ ไม่ตรง: CONTAINERHASLK…0001F⚠ ABCU0686534⚠ XYZU0940767121.000121.000LCL/CFS
⚠ ต้องตรวจสอบ: MARKSHASLK…0001BXYZU0940767XYZU0940767964.290964.290LCL/CFS
⚠ ไม่มีเอกสาร ENTERHASLK…0001—ABCU0686534—225.000LCL/CFS

ตัวอย่างประกอบเท่านั้น เลข B/L และเลขตู้สมมติ รายงานจริงมีคอลัมน์มากกว่านี้

แดงไม่ตรงกัน ต้องแก้หรือยืนยันก่อนยื่น
ส้มอาจเป็นแค่การตัดบรรทัดต่างกัน ให้คนดูยืนยัน
เหลืองไม่มีเอกสาร ENTER ให้เทียบ
เขียวผ่าน ไม่พบจุดผิด

หัวข้อที่เทียบทุก B/L

  • CONSIGNEE และ TAX ID vs NOTIFY
  • CONTAINER NO. และ STATUS (CY / LCL / LCL/CFS)
  • จำนวนและชนิดหีบห่อ, G.W., MEAS.
  • MARKS และ DESCRIPTION
  • SHED NO., ประเทศปลายทาง, CARGO MOVEMENT

ขึ้นแดงทันทีเมื่อเจอ

  • DG (CLASS / UN)
  • REEFER TEMP
  • INTRANSIT / TRANSHIPMENT
  • B/L ที่มีใน ENTER แต่หายจาก MANIFEST (แถววิกฤต)
  • ยอดรวมแถว TOTAL ไม่ตรงกับที่เอกสารระบุ

ใช้กับ Claude Code

สำหรับคนที่ใช้ Claude Code อยู่แล้ว ให้ Claude ตรวจและอธิบายผลให้ และเพิ่มแบบฟอร์ม ENTER ใหม่ได้เอง

git clone https://github.com/Rattanao/Freight-links.git %USERPROFILE%\.claude\skills\check-edi-freight-links

เปิด Claude Code ใหม่ ไปที่โฟลเดอร์งาน แล้วพิมพ์ เช่น “ตรวจ EDI SHED NO. 0141”
